# 강수정 | Personal Portfolio

의료행정 분야를 배우며 배려와 책임감을 바탕으로 성장하는 강수정의 개인 포트폴리오입니다.

## 구성
- 소개 및 관심 분야
- 주요 강점
- 아르바이트 및 대학 생활 경험
- 교육 및 학습
- 중요하게 생각하는 가치

## 실행 방법
별도 빌드 과정 없이 `index.html`을 브라우저에서 열면 확인할 수 있습니다.

## GitHub Pages 배포
저장소의 **Settings → Pages**에서 배포 소스를 **Deploy from a branch**로 설정하고, 브랜치를 **main**, 폴더를 **/(root)**로 선택한 뒤 저장하면 됩니다.

## 기술
- HTML
- CSS
- Responsive layout
